# Exercício de ES6+

Este projeto cria um array de objetos com o nome e a nota de estudantes. Em seguida, utiliza uma função para retornar somente quem obteve nota maior ou igual a 6.

## Recursos utilizados

- `const` para declarar valores que não serão reatribuídos;
- arrow function (`=>`);
- método `filter()` para criar um novo array;
- desestruturação de objetos para acessar a propriedade `nota`;
- módulos ES6 com `export` e `import`;
- `console.table()` para exibir os resultados de forma organizada.

## Como executar

É necessário ter o Node.js instalado. Dentro da pasta do exercício, execute:

```bash
npm start
```

Para rodar a verificação automática:

```bash
npm test
```

## Regra de aprovação

São considerados aprovados os estudantes com nota maior ou igual a 6.
