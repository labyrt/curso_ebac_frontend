# Exercício de ES6+

Projeto com um array de estudantes e uma função que usa `filter()` para selecionar quem atingiu a média. Além da execução no terminal, a branch inclui uma interface web responsiva para alterar a nota mínima e visualizar o resultado imediatamente.

## Recursos utilizados

- `const`, arrow functions e parâmetros padrão;
- método `filter()` e desestruturação de objetos;
- módulos ES6 com `export` e `import`;
- manipulação do DOM e renderização dinâmica.

## Abrir no navegador

Abra `index.html` ou publique a raiz da branch na Vercel.

## Executar no terminal

```bash
npm start
npm test
```

A média padrão é 6, mas a interface permite testar outros valores.
