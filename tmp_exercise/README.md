# Calculadora de IMC — ReactJS

Projeto desenvolvido em ReactJS para calcular automaticamente o Índice de Massa Corporal (IMC) a partir da altura e do peso informados.

## Funcionalidades

- Campos de altura em metros e peso em quilogramas;
- Cálculo automático, sem botão de envio;
- Resultado formatado com duas casas decimais;
- Classificação do IMC;
- Destaque automático da classificação na tabela;
- Botão para limpar os campos;
- Validação de valores positivos;
- Interface responsiva e acessível.

## Fórmula utilizada

```text
IMC = peso / altura²
```

## Como executar

É necessário ter o Node.js instalado.

```bash
npm install
npm run dev
```

Depois, abra o endereço exibido no terminal.

## Tecnologias

- ReactJS
- TypeScript
- CSS responsivo
- Next.js/Vinext
