# Agenda de Contatos — React + Redux

Projeto desenvolvido para o exercício de criação de uma lista de contatos utilizando:

- React
- Redux Toolkit
- React Redux
- Styled Components
- Vite

## Funcionalidades

- Adicionar contatos
- Editar contatos
- Remover contatos
- Validar nome, e-mail e telefone
- Pesquisar contatos
- Persistir os dados no `localStorage`

## Como executar

```bash
npm install
npm run dev
```

## Gerar a versão de produção

```bash
npm run build
```
